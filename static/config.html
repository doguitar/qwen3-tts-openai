Your named voices

Public name is what clients type. Maps to is either an existing public voice ({folder}-{speaker}) or a speaker id from the checkpoint (spk_id). Checkpoint folder is the directory name under /models; leave it blank when Maps to is already a public voice or the speaker exists on only one checkpoint. Preset instructions are always sent first; extra instructions from the request are appended after one space. Voice Design needs a preset or request instructions.

Clone presets

A clone preset is a public name plus a wav and the transcript of that wav. It uses a Base checkpoint. Upload is required when you add or replace the wav. These names appear on Speakers and GET /v1/voices.
